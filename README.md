# Nightjar Reads — LNReader plugin

An unofficial [LNReader](https://github.com/LNReader/lnreader) plugin (extension) for [nightjarreads.com](https://nightjarreads.com/), a site hosting translated and original web novels.

## Install in the app

1. In LNReader, go to **Settings → Repositories**.
2. Add this repository URL:

   ```
   https://raw.githubusercontent.com/RevDev909/lnreader-nightjarreads/main/.dist/plugins.min.json
   ```

3. Install the **Nightjar Reads** plugin from the repository.

## What it supports

- Browse popular novels
- Novel details: title, author, genres, status, synopsis, cover, full chapter list
- Chapter reading (free chapters)
- Search
- Locked (premium) chapters show a notice instead of failing
- Commit directly to the main branch.
